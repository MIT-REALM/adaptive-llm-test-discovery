**Adaptive Test Case Discovery for LLM-Assisted Decision Making in High-Stakes Domains**

[Anjali Parashar](https://github.com/anjaliParashar),
Carson Sobolewski,
Yingke Li,
Fei Chen, and
[Chuchu Fan](https://chuchu.mit.edu/)

Laboratory for Information & Decision Systems (LIDS) · [REALM](https://aeroastro.mit.edu/realm/) · MIT

</div>

Sample-efficient adaptive experimental design for discovering challenging test scenarios for LLM-assisted decision pipelines, using a flow-matching surrogate that balances utility and mutual-information exploration.
